# Portfólio · Carmen Fernandes

Site de portfólio (Vite + React + TypeScript).

## Executar localmente
1. `npm install`
2. `npm run dev`

## Onde editar o conteúdo
- `src/types/portfolio.ts`: perfil (`INITIAL_PROFILE`) e projetos (`INITIAL_PROJECTS`), incluindo links de vídeo.
- `public/images/`: imagens dos projetos (referenciadas como `/images/nome.jpg`).
- Redes sociais: preencher `socials` em `INITIAL_PROFILE` (as vazias não aparecem).
